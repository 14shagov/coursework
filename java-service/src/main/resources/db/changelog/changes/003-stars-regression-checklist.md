# Regression-набор для RAG по теме «звезды»

После обновления сидов:
1. Перезапустить сервисы с переинициализацией БД (или на чистой БД).
2. Вызвать `POST /api/admin/embeddings/init`.
3. Для вопросов ниже проверить, что в ответе API есть `bestScore` и `threshold`.

## Вопросы и ожидаемая проверка

- «Что такое звезда?»
  - Ожидание: `bestScore >= threshold`.
- «Какие этапы эволюции у звезды?»
  - Ожидание: `bestScore >= threshold`.
- «Какие бывают типы звезд?»
  - Ожидание: `bestScore >= threshold`.
- «Как масса влияет на жизнь звезды?»
  - Ожидание: `bestScore >= threshold`.
- «К какому спектральному классу относится Солнце?»
  - Ожидание: `bestScore >= threshold`.
- «Что такое белый карлик и красный гигант?»
  - Ожидание: `bestScore >= threshold`.

## Негативный/пограничный пример

- «Как варить пасту аль денте?»
  - Допускается `bestScore < threshold` (нерелевантный вопрос вне домена).
